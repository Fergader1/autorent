AUTORENT - INTERFAZ WEB

1. Copia index.html en src/main/resources/static de tu proyecto IntelliJ.
2. Si no existe static, crea esa carpeta dentro de resources.
3. Reinicia AutorentApplication y abre http://localhost:8080/.
4. No abras el HTML con doble clic: necesita el servidor Spring Boot.

Incluye registro de autos y clientes, creacion/finalizacion de alquileres,
consultas por ID, lista y filtro local de autos disponibles, y respuesta HTTP/JSON.
No requiere cambiar pom.xml ni instalar bibliotecas.

Prueba: registra un auto y un cliente; sus IDs se rellenan en el formulario
 de alquiler. Elige los dias y crea el alquiler. El auto desaparecera de
 disponibles. Finaliza usando el ID del alquiler; el auto reaparecera.
Los datos dependen de H2 y se pierden al reiniciar el backend.

Los campos de deposito, kilometraje, baja y mantenimiento de la imagen de
 referencia no se incluyen porque la API actual no ofrece esas operaciones.

Verificacion: sintaxis JavaScript y pruebas de solicitudes/respuestas simuladas
(201, 409, respuesta no JSON y desconexion). Pendiente prueba visual e integracion
con el backend real: el navegador de revision no pudo acceder al servidor local.

   - El documento HTML está estructurado con etiquetas `<html>`, `<head>`, y `<body>`. Dentro del `<head>`, se incluyen metadatos, el título de la página y estilos CSS para el diseño visual.

   - Hay formularios para registrar vehículos y clientes, así como para crear y finalizar alquileres. Cada formulario tiene campos de entrada (input) para capturar información relevante, como placa del vehículo, marca, modelo, año, precio por día, nombre del cliente, documento, teléfono y correo electrónico.
4. **Interactividad con JavaScript**:
   - Se utiliza JavaScript para manejar la interactividad de la página. Esto incluye:
